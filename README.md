# HR Analytics — Employee Attrition Analysis

## Project Overview
This project analyzes employee attrition data to identify workforce patterns
and explore factors associated with employee turnover.

## Tools & Technologies
- Python (Pandas, Matplotlib)
- SQL Server
- Microsoft Power BI

## Dataset
The dataset contains 1,470 employee records and 35 columns.

## Key Findings
- Overall attrition rate: 16.12%.
- Sales department attrition rate: 20.63%.
- Attrition rate among employees working overtime: 30.53%.
- Attrition rate among employees not working overtime: 10.44%.

## Project Workflow
1. Data quality checks.
2. Exploratory Data Analysis using Python.
3. SQL queries to analyze employee attrition.
4. Interactive dashboard development using Power BI.
